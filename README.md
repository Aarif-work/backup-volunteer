# backup-volunteer

A new Flutter project for the volunteer management platform.

## Project Updates

### New Features Added

#### Student Request Management
Students can now submit requests from the student application, and volunteers can review and manage them inside the volunteer app.

**Request Types:**
* Leave Requests
* Fee Requests
* Achievement Requests

**Volunteers can:**
* Accept requests
* Reject requests
* View request history
* Track request status

---

#### Student Profile Viewing
Volunteers can now view student profiles inside the app.

**Profile details include:**
* Student information
* Achievement records
* Leave history
* Fee request history

This section is view-only for volunteers.

---

#### Enhanced Expense Management
The expense system has been improved with:
* Bulk expense upload
* Multiple expense entries in one submission
* Refund tracking
* Approval status tracking
* Optional proof image upload

---

#### Expense Visibility Control
While uploading expenses, volunteers can now choose:
* Show to all volunteers
* Private storage only

This helps separate public foundation activities from private records.

---

#### Improved Refund Tracking
The refund system now supports:
* Requested refund amount
* Approved refund amount
* Refund received
* Remaining balance tracking

**Supports:**
* Volunteer-paid expenses
* Foundation-paid expenses
* Partial refunds

---

#### Advanced Filtering
Added filters for:
* Expense category
* Approval status
* Refund status
* Student request type
* Student name
* Date-based records

---

#### Report Export System
Volunteers can now download:
* PDF reports
* Excel reports

**Reports include:**
* Expense records
* Refund details
* Student request summaries
* Volunteer activity history

*Note: Images and videos are excluded from exported reports.*

---
